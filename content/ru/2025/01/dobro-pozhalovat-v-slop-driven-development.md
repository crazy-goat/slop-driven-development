# Добро пожаловать в Slop Driven Development!

Это первая запись в моём новом **Slop Driven Development**.
Статьи написаны в Markdown и обслуживаются из RAM с помощью Symfony + Workerman.

## Возможности

- **Без базы данных** — статьи — это файлы `.md` на диске
- **Мгновенная скорость** — всё в RAM после запуска
- **Многоязычность** — полная поддержка переводов через `translation_key`
- **SEO** — hreflang, Open Graph, канонические URL
- **Markdown** — пиши в Markdown, получай HTML

```php
<?php
echo "Slop Driven Development rulez!";
```

Приятного чтения!
